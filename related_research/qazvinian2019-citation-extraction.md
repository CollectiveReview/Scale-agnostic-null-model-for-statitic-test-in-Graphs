# Automatic Extraction of Citation Contexts for Research Paper Summarization

**Keywords:** citation extraction, text mining, research summarization, scientific papers, NLP
**Year:** 2019
**Authors:** Qazvinian, V., & Radev, D. R.

## Summary

This paper presents methods for automatically extracting citation contexts from scientific papers using natural language processing techniques. The research focuses on identifying citation sentences and the surrounding context that explains why a citation is made.

## Key Contributions

- Automated citation context extraction algorithms
- Machine learning approaches for citation sentence classification
- Dataset for evaluating citation context extraction

## Relevance

For citation context analysis, understanding how to automatically extract and process citation contexts is crucial. This work provides practical methods and algorithms that can be applied to large-scale literature analysis.
