# Citation Context Analysis in Scientific Literature

**Keywords:** citation context, scientific literature, citation analysis, literature review, citation function
**Year:** 2020
**Authors:** Teufel, S., Siddharthan, A., & Tidhar, D.

## Summary

This research presents a comprehensive framework for analyzing citation contexts in scientific papers. The work focuses on understanding why authors cite other works and how citations function within the discourse structure of scientific writing.

## Key Contributions

- Developed a citation function classification scheme
- Created annotated corpus for citation context analysis
- Demonstrated the importance of citation context for literature reviews

## Relevance

This research is foundational for understanding citation context analysis. It provides frameworks and methodologies that are essential for any work involving the analysis of how papers cite other works and the semantic relationships between citing and cited papers.
