# Related Research Database

This directory contains markdown files with information about related research that can be suggested by the bot.

## Structure

Each research entry should be a markdown file with the following format:

```markdown
# Research Title

**Keywords:** keyword1, keyword2, keyword3
**Year:** Publication year
**Authors:** Author names

## Summary

Brief summary of the research...

## Relevance

Why this research is relevant for citation context analysis...
```

## Usage

The bot will scan these files when analyzing new papers and suggest the most relevant ones based on keyword matching and content similarity.
