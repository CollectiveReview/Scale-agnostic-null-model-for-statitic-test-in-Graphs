# Papers Directory

This directory contains research papers for citation context analysis.

## Structure

Each paper should be added as a markdown file with the following format:

```markdown
# Paper Title

**Authors:** Author names
**Year:** Publication year
**Venue:** Conference/Journal name

## Abstract

Paper abstract here...

## Key Contributions

- Main contribution 1
- Main contribution 2

## Related Work

(This section will be automatically populated by the bot)
```

## Adding a New Paper

1. Create a new markdown file in this directory with a descriptive name (e.g., `smith2023-citation-context.md`)
2. Fill in the paper details following the template above
3. Commit and push the file
4. The GitHub Actions bot will automatically create a PR suggesting related research
